# Kip Ecklund

I build [Nizlo](https://nizlo.com/), a Windows-first remote monitoring and management platform for MSPs and lean IT teams.

## Open MSP operations resources

- [Nizlo MSP Operations Resources](https://izikipizi.github.io/nizlo-msp-operations-resources/) — free, ungated checklists, worksheets, templates, and calculators for MSP operations.
- [RMM First-Endpoint Activation Troubleshooting Checklist](https://izikipizi.github.io/nizlo-msp-operations-resources/rmm-first-endpoint-activation-troubleshooting-checklist.html) — trace installer execution, service state, tenant enrollment, DNS, TLS, proxy, security-control events, and verified first telemetry.
- [RMM Agent Offline Troubleshooting Checklist](https://izikipizi.github.io/nizlo-msp-operations-resources/rmm-agent-offline-troubleshooting-checklist.html) — triage device scope, power state, service health, DNS, TLS, proxy, firewall, clock, identity, update, remediation, and recovery evidence before closing an offline-agent incident.
- [RMM Duplicate Device or Cloned Agent Identity Troubleshooting Checklist](https://izikipizi.github.io/nizlo-msp-operations-resources/rmm-duplicate-device-identity-troubleshooting-checklist.html) — preserve identity evidence, trace golden-image, reinstall, shared-key, and stale-import causes, contain automation, reconcile records, and prevent recurrence.
- [RMM Patch-Compliance Calculator](https://izikipizi.github.io/nizlo-msp-operations-resources/rmm-patch-compliance-calculator.html) — calculate strict verified compliance from an explicit endpoint denominator without hiding failures, pending reboots, exclusions, stale devices, or unknown states.
- [RMM RFP Template and Buyer Guide](https://nizlo.com/guides/rmm-rfp-template?utm_source=github&utm_medium=founder_profile&utm_campaign=rmm_rfp_template) — define scope, evidence requests, security and implementation questions, pricing and exit terms, pilot acceptance, and an issue-to-decision workflow before vendor selection.
- [RMM Vendor Exit Plan Checklist](https://izikipizi.github.io/nizlo-msp-operations-resources/rmm-vendor-exit-plan-checklist.html) — 32 controls for contracts, inventory, exports, automation, credentials, replacement proof, coexistence, cutover, agent removal, access revocation, data disposition, acceptance, and stabilization.
- [RMM Audit Log Review Checklist](https://izikipizi.github.io/nizlo-msp-operations-resources/rmm-audit-log-review-checklist.html) — 24 controls for actor, tenant, endpoint, privileged-action, outcome, retention, export, monitoring, investigation, exception, and retest evidence.
- [RMM Security Evidence Register](https://izikipizi.github.io/nizlo-msp-operations-resources/rmm-security-evidence-checklist.html) — turn 30 security claims into requested evidence, controlled validation, named risk ownership, time-bounded exceptions, remediation, and retesting.
- [RMM API Integration Preflight Checklist](https://izikipizi.github.io/nizlo-msp-operations-resources/rmm-api-integration-preflight-checklist.html) — 18 evidence checks covering identity, tenant isolation, data handling, rate limits, webhooks, audit evidence, and rollback.
- [RMM Vendor Evaluation Checklist](https://nizlo.com/guides/rmm-evaluation-checklist) — a practical evidence-based framework for comparing RMM platforms.
- [Nizlo Security Architecture](https://nizlo.com/security) — current product security controls, operational boundaries, and security-reporting information.

I maintain these resources through Nizlo. They are intended as practical starting points, not certifications, legal advice, or guarantees.
